## Design concept: "the statement"
The page reads like a well-set financial statement / ledger: a strict left rail of section numbers and labels, wide hairline rules (`rule`), tabular figures, generous but disciplined whitespace. One memorable thing: the FinTech hero convergence (made legible). Everything else is quiet. No gradients, shadows, emoji; no new hues (opacity of tokens OK).

### Tokens
- Palette unchanged (7 tokens). Keep `--radius-card`, may reduce use: cards 10-12px, buttons pill. Add only non-colour tokens (e.g. `--header-h`, spacing) to `@theme`/`:root`.
- Fonts (next/font/google, edit only the font imports in app/layout.tsx, NOT metadata): replace Geist with **IBM Plex Sans** (400,500,600) as `--font-sans` and **IBM Plex Mono** (400,500) as `--font-mono`. Mono is used only for numerals/periods/status/years (with `font-variant-numeric: tabular-nums`), not for generic labels. Update DESIGN.md Typography section accordingly (allowed; it's docs).
- Scale (clamp-based): body 17px/1.6 sans; small 14-15px; h2 `clamp(28px,4vw,44px)` weight 600, tracking -0.025em, line-height 1.1; h1 case pages same; hero intro h1 `clamp(36px,6vw,64px)`. Line length <= 68ch for prose. Avoid all-caps labels and tracked eyebrows: section label is sentence case.
- Contrast: `muted` (#57584F) on ground/surface passes AA; teal on ground passes. Don't use `muted` at reduced opacity for text. Rule colour only for lines.
- Global: `:focus-visible { outline: 2px solid var(--color-system); outline-offset: 3px; }`; `html { scroll-padding-top: var(--header-h) }`; `overflow-x: clip` on body; reduced-motion guard `@media (prefers-reduced-motion: reduce){html{scroll-behavior:auto}*{transition:none!important}}`.
