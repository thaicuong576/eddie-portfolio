## Design direction ("calm and exact", a ledger/statement feel)
Skill note: the design-taste skill's no-mono/no-rules/no-index-number rules conflict with this project's brief (numbered sections come from `content/sections.ts`, ledger look, rule token). Where they conflict, the project brief wins. Keep the skill's anti-slop spirit: no gradients, no shadows at rest, no glass, no icon-topped cards, no emoji, no identical-card rows with no variation, headlines at most two lines, one grid, equal margins, real headings in order.
- **Type:** keep Geist (sans) for text. Use Geist Mono ONLY for tabular things: section numbers, periods/years, status, tags, so figures align. Optionally switch display to another `next/font/google` family only if it clearly helps; Geist is acceptable. Set `font-variant-numeric: tabular-nums` where numbers align. Scale: one large display (clamp 40-96px, tracking -0.03 to -0.04em, leading ~1.0), section heading clamp(30px,4vw,52px), body 16-18px/1.55, small 13-14px. Body text in `ink` or `muted` (muted #57584F on ground passes AA; do not go lighter or use opacity below that on text).
- **Frame:** one container (max ~1240px, px 20 mobile / 40 desktop), consistent section padding (~96px mobile / 144px desktop). Section layout: 12-col grid; left column (sticky on desktop) holds the section number + label + heading, right column holds the content. This fills width instead of a plain column. Rhythm via spacing and alternating surface/ground bands (tone step, no double lines).
- **Detail:** hairline `rule` borders are allowed (they are the ledger look) but never two stacked. Cards use `surface` + 1px `rule`, radius 16px (`--radius-card`), no shadow. Hover/focus: border to `system`, small translate of arrow (CSS only, wrap in `motion-safe:`), `focus-visible:outline-2 outline-offset-2 outline-system` on every link/button (define once in globals.css via `:focus-visible`). Buttons fully round.
- Add `scroll-padding-top` / `scroll-mt` matching the real header height so anchors land below the header.
- Eyebrow numbers keep coming from `sectionEyebrow()`; keep calling it.

## Accessibility

Headings in order: one h1 per page, h2 per section, h3 for cards/panels. `nav` has `aria-label`. Hint text in hero stays `aria-hidden` decorative. Letters flying are `aria-hidden`; the wordmark link has aria-label.
