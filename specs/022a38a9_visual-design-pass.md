## Design direction ("the ledger")
Calm, exact, tabular. Think a well-set financial statement: hairline rules, tabular numerals, mono for figures/labels, generous but disciplined rhythm, no shadows/gradients/emoji, teal as only accent, butter ground. Palette tokens unchanged (opacity variants OK, e.g. `bg-system/5`, `border-rule/60`).

### Global (globals.css / layout.tsx)
- Keep the 7 tokens verbatim. Add non-colour tokens as needed (spacing, `--header-h`: 56px mobile / 72px desktop, used by hero, scroll-mt, sticky offsets).
- Fonts: may keep Geist + Geist Mono (acceptable) or swap sans for a more distinctive pair via next/font/google (e.g. a refined grotesk/serif display for headings + Geist Mono). Whatever is chosen, keep `--font-sans`/`--font-mono` variables. Enable `font-variant-numeric: tabular-nums` on figures/years. Define a type scale with `clamp()` for h1/h2; body 16–18px, min 12px for mono labels, line length ≤ 68ch.
- Global `:focus-visible` ring: 2px `system` outline, 3px offset, on all links/buttons (on teal fills use ground-colour offset). `html{scroll-padding-top: var(--header-h)}`; `scroll-behavior:smooth` inside `@media (prefers-reduced-motion: no-preference)`. `body{overflow-x:clip}` guard, but also fix real causes of overflow.
- Shared utility classes in globals.css (via `@layer components` or `@utility`): `.eyebrow` (mono, uppercase, tracked, system), `.section` wrapper (max-w ~1200, px-5 sm:px-10, py-20 sm:py-28), `.card`, `.link-arrow`, `.chip`. Small CSS-only hover: border colour to system, arrow translateX 2px, 150–200ms, wrapped in `motion-safe:`.
- Muted `#57584F` on ground `#F2EBD3` ≈ 6:1 and teal on ground ≈ 6.5:1: both pass AA; do not use muted at <1 opacity for text. Rule colour is decorative only.

### ScrollHero (keep the idea; fix legibility on phones)
